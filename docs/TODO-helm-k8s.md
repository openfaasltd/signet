# Signet — Helm chart + end-to-end k8s validation tracking

Status: in progress (started 27 Aug 2026)
Owner: agent session
Repo: `signet` (this directory)

## Goal

Following the OpenFaaS fashion: on Kubernetes, signet's keys/secrets must be
created by a Helm chart, shipped through Kubernetes Secrets, and mounted as
files — never as environment variables. Validate end-to-end in this sandbox VM.
